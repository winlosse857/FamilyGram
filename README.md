# Zvon

Простой мессенджер: регистрация и личные чаты 1 на 1. Сервер — Python (Flask + Socket.IO + SQLite), клиент — HTML/CSS/JS, в Android-приложение упаковывается через Capacitor.

## Как это устроено
APK — только «окно». Сообщения хранит и пересылает сервер, поэтому его нужно где-то запустить, чтобы он был доступен из интернета по HTTPS.

## Запуск локально
```bash
pip install -r requirements.txt
python app.py
```
Открой http://127.0.0.1:5000.

## Сервер в интернете
Подойдёт любой хостинг Python. Команда запуска: `gunicorn -k gthread --threads 100 -w 1 app:app`. Для сохранения базы после перезапуска настрой постоянное хранилище и `DB_PATH`.

## Android APK
В GitHub Actions добавь переменную репозитория `SERVER_URL` с HTTPS-адресом сервера. Затем открой Actions → Build APK → Run workflow. APK появится в Artifacts; для публикации релиза создай тег вида `v0.1.0`.

## Ограничения
Нет групп, файлов, push-уведомлений, сквозного шифрования и защиты от спама. Переписка хранится на сервере без сквозного шифрования.
